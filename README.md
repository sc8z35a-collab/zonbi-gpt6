# DEADZONE — 末日戦線 / STORM OPERATIONS（ULTRA画質）

## 概要
高性能スマートフォンを主な対象とする、荒廃都市のシングルプレイヤー3DゾンビサバイバルFPSです。HTML/CSS/JavaScript、Three.js r158による静的サイトです。インストール、アカウント、サーバー処理、APIキーは不要です。

## 完成済みの機能
- 一人称の銃撃、移動、ダッシュ、精密照準、反動、命中エフェクト。
- ヘッドショット2.2倍、装甲による胴体ダメージ軽減、散弾の距離減衰。
- 手動／自動リロード、無限の予備弾、購入済み武器の切り替え。
- 5段階のゾンビ、段階別の体力・速度・攻撃力・報酬。
- ウェーブ進行、クリア報酬、体力回復、死亡時のリザルトと再出撃。
- 6種類の武器、6系統の永続強化、所持金と購入内容の自動保存。
- 武器庫・図鑑・操作ガイド・設定・一時停止ダイアログ。
- 40mレーダー、HP・装甲・弾数・所持金・敵残数・キルフィード。
- Web Audioによる環境音、射撃、被弾、購入、リロード音。

## STORM OPERATIONS：今回追加した機能

### 環境と射撃演出
- 2,800本の雨筋、120個の水面の波紋。雨はプレイヤー周辺に追従します。
- 20〜34秒間隔のゆっくりした雷光と雷鳴。OSの動きを減らす設定では雷光を省略。一時停止画面で雨・雷を切り替え可能。
- 真鍮の薬莢排出・回転・重力落下・地面での反発、壁・路面への着弾痕、火花、破片。
- 武器スライドの後退、リロード中のマガジンと手の動き、M110の円形スコープ。
- 衝突や着弾の判定はゲーム用の近似形状です。建築物の破壊は未実装です。

### 戦術アイテムと補給
| アイテム | 操作 | 効果 | 価格 / 上限 |
| --- | --- | --- | --- |
| M67手榴弾 | ◉ / G | 1.8秒後に爆発。半径5.5m、中心400ダメージから距離減衰 | ₡120 / 5個 |
| 回復キット | ✚ / H | 2秒治療してHPを60回復 | ₡100 / 3個 |

初回または旧セーブ移行時は手榴弾2個・キット1個を用意。残数は保存され、再出撃で自動補充されません。武器庫の**補給 / SUPPLY**タブで購入できます。

手榴弾は重力と簡易反発を持ち、投擲クールダウンは1.2秒。爆発には火球・衝撃波・飛散物・照明・距離に応じた画面揺れと爆発音を追加。自分も爆風ダメージを受けます。治療中は移動可能、射撃不可。被弾で中断しますが、キットは消費しません。全回復時の使用も防止。武器庫・停止中は起爆・治療の時間も進みません。

### 作戦目標と連続撃破
毎ウェーブ「頭部を狙え」「感染体を排除」「爆破で一掃」の目標を提示。達成報酬は `₡120 + ウェーブ × 40`、各目標からの支給は一度のみ。5秒以内の連続撃破はCHAIN KILLとなり、2体目から1撃破につき₡10ずつ増加、最大₡60の追加報酬。HUDに進捗・報酬・残り時間・治療進行を表示し、リザルトにも目標達成数と追加報酬を表示します。目標進行は出撃内のみ、獲得金は永続保存です。

### ゾンビモデルとモーション
- 骨盤、背骨、首、頭、顎、股関節、膝、足首、肩、肘、手首、10本の指の関節を持つ階層モデル。
- 皮膚・布地のテクスチャ、顔の凹凸、眼窩、鼻、頬、耳、歯、爪、縫い目、破れ、装甲。
- 実際の移動距離に同期した歩行サイクル。走る個体と重量級で姿勢・振幅・歩幅を変更。
- 左右非対称のよろめき、腰の揺れ、胸の呼吸、頭の遅れ、手首・指の細かな動き。
- 体力が少ないと足を引きずり、移動速度も低下。
- 攻撃は**予備動作 → 振り → 接触判定 → 戻り**の段階構成。接触フレームでのみダメージが発生し、離れると回避できます。
- 頭部／胴体と命中方向に応じた被弾リアクション。
- 頭部命中による予備動作の中断（一部の敵のみ）。
- 後方転倒、横倒れ、膝から崩れる3系統の死亡アニメーション。全身を一枚の板のように回す方式ではありません。
- 頭・胴体の命中判定はアニメーション後の関節位置に追従します。

これらは独自のプロシージャル3D表現です。フォトスキャン、モーションキャプチャ、物理ラグドールではありません。

### PCの操作
WASD／矢印で移動、マウスで視点、左クリック射撃、右クリック精密照準、Shiftダッシュ、Rリロード、1〜6／Q／ホイールで購入済み武器の切替、G手榴弾、H治療、B武器庫、Esc／P一時停止（Pで再開）。マウス感度は設定の感度値に従い、照準中・スコープ中は減速します。最初のクリックはマウス固定のみで射撃しません。ポインターロック非対応の埋め込みでは左ドラッグでも視点を操作できます。

## 描画設定
**ULTRA固定**です。
- 端末のdevicePixelRatioをそのまま使用。スマホだからという理由で解像度を下げません。
- アンチエイリアスON。
- 4096×4096シャドウマップ。
- 最大対応異方性フィルタリング、材質の凹凸・粗さ、環境反射。
- 浮遊する灰は1750粒。
- 自動画質低下・LOWモードはありません。

高負荷・発熱・消費電力の増加は想定されます。ブラウザやGPUの上限は越えられず、フレームレートを保証するものではありません。

`localStorage['deadzone-touch-v2']`:
```json
{"sensitivity":1,"adsSensitivity":0.55,"scale":1,"opacity":0.85,"autoSprint":true,"aimAssist":true,"haptics":true}
```

現在の位置・敵・体力・戦闘中ウェーブはメモリ上のみです。再出撃はウェーブ1から。死亡しても所持金・購入済み武器・強化は保持。端末間同期はなく、ブラウザのサイトデータを消すとセーブも消えます。保存データはクライアントから変更可能で、競技用の不正対策はありません。

## バグ修正パス（2026-09）
約100件の不具合を修正しました。主な内容：
- **衝突判定**：車両・バリケード・土嚢を向き付きの箱、ドラム缶を円柱として判定。車の前後をすり抜ける、何もない空中で弾が止まる、バリケードの上を撃てない問題を解消。手榴弾も実形状で反射し、車の屋根に乗ります。
- **射撃**：脚・腕にも命中判定（0.8倍）。フルオートの端数クールダウンを繰り越して規定RPMを実現。曳光弾は実際の銃口から発射。被弾リアクションの左右を敵の向き基準に修正。遮蔽物越しのエイムアシスト・近接攻撃・爆風を無効化。
- **武器**：戦場での武器切替で各武器の残弾を保持（切替による無料リロードを防止）。PCで1〜6／Q／ホイールで切替可能。
- **UI・入力**：一時停止からの武器庫・ガイド・設定を閉じると一時停止画面へ戻る。背景タップで閉じる。一時停止中は環境音を停止。スクロールやURLバーの表示変化でタッチ入力が解除されない。フォーカス管理、aria状態、Safari向けぼかし、safe-area、スコープ中の照準表示を修正。
- **保存**：旧セーブの補給品の片方欠落で0個になる問題、撃破ごとの同期書き込み、保存失敗トーストの連発を修正。雨・雷の設定を保存。
- **演出・性能**：爆発ごとのライト追加によるシェーダー再コンパイルを解消。ゾンビ・破片・効果音バッファのジオメトリ／バッファを共有。空ドームと影カメラをプレイヤーに追従させ、地平線をフォグ色に馴染ませる。HUDのDOM書き込みを変更時のみに削減。
- **その他**：クリア報酬の回復量を実値で表示、治療中に満タンになった場合はキットを消費しない、手榴弾がない時の爆破目標を撃破目標に置換、体力バーを左端基準で減少、など。
